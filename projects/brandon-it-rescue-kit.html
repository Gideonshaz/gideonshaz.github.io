IT Rescue Kit

A portable, all-in-one Windows diagnostics and recovery toolkit, designed for portable system diagnostics, Windows repair, and recovery workflows, with support for a bootable rescue drive.

How it works

System information

Displays Windows version, computer name, CPU, RAM, GPU and storage details.

Windows repair tools

Provides repair workflows for tools including SFC, DISM and CHKDSK.

Rescue Drive Manager

Supports a portable rescue drive with Ventoy and organized ISO resources.

Bootable recovery

The rescue SSD was tested with Windows, Linux and Hiren’s BootCD PE images.

Portable diagnostics

Integrates utilities such as CrystalDiskInfo, GPU-Z and HWiNFO.
