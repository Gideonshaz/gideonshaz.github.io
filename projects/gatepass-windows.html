Gate Pass Management System

A purpose-built out-of-office management workflow connecting employee kiosk requests, supervisor decisions, HR acknowledgement and security movement tracking.

Three connected applications

Employee Request Kiosk

Windows app for submitting out-of-office requests.

Admin Monitoring App

Mobile app for authorized administrators to monitor request progress.

Security Guard Kiosk

Separate Windows kiosk for clock-out and clock-in only. It does not create requests.

How it works

Employee kiosk

Staff submit gate pass requests using the Windows kiosk.

Approval routing

Requests are routed to the assigned supervisor or manager for approval or rejection.

HR acknowledgement

Approved requests proceed to HR for acknowledgement through Outlook.

Security check-out and return

Security uses the dedicated Windows kiosk to record staff departure and return.

Central records

SharePoint supports the workflow's central records and tracking.

Employee Request Kiosk · Submission Workflow

The main Windows kiosk is the starting point for an out-of-office request. Employees enter their details, select the relevant request information, and submit a gate pass for approval.

Employee identification

The kiosk captures employee information, including the employee code, and uses configured staff records to determine the appropriate section and approval routing.

Request submission

The employee provides the purpose and planned movement details, then submits the gate pass through the kiosk.

Supervisor decision

The assigned supervisor or manager receives the request and can approve or reject it.

HR acknowledgement

Approved requests proceed to HR, where acknowledgement is handled through the Outlook email workflow.

Security movement record

Once the required approvals and acknowledgement are complete, security can find the approved pass and record departure and return using the separate Windows security kiosk.
